    no missing glyphs / no miscolored regions / no missing geometry / no
    coordinate drift > 2 pixels". Pixel-exact matching is NOT required (Qt
    AA text and X11 core fonts will always differ at the subpixel level).

    For each driver N in {1, 2, 3, 4}:

    ```bash
    cd $MEFISTO

    # 1) Qt run — open a fresh terminal so stderr is isolated.
    QT_QPA_PLATFORM=xcb pp/ppxvtest${N}_qt
    # (the driver opens a window; observe it, let the SLEEP holds run)

    # 2) X11 run — in a separate terminal.
    pp/ppxvtest${N}
    # (legacy X11 window)
    ```

    Arrange the two windows side by side (or overlay and toggle). Verify
    per the D-27 rubric:

    **For each of xvtest1..4:**

    a. **Geometry present and in the same place:** every line, polygon,
       rectangle, and arc the X11 backend shows must appear in the Qt
       backend at the same logical position (±2 pixel tolerance).
    b. **Colors match:** each colored element shows the SAME color in both
       backends (within 1 bit per channel on a 24-bit display, which to
       the naked eye is indistinguishable). If any element is visibly a
       different hue, imposed_defaults_fill drifted from xvuelc.c:378-461
       or xvactivervb_'s bulk-load path is broken.
    c. **Text labels are all present, in readable DejaVu Sans Mono on Qt,
       in the X11 server font on X11, but semantically equivalent:** same
       content, same approximate position, no clipping against any
       rectangle or line. Subpixel differences in glyph shape are
       ACCEPTED per D-27.
    d. **No missing glyphs / missing geometry:** if X11 shows a label the
       Qt backend does not (or vice versa), xvtexte_/xvftexte_ is broken.
    e. **No miscolored regions:** if X11 shows a filled region in one color
       and Qt shows it in a different color, xvcouleur_ or the brush-sync
       in applyPen (02/D-20) is regressed.

    Document any per-driver findings in a brief note for Task 4's
    03-04-SUMMARY.md (check number + expected/actual).

    Optional: if you have a HiDPI display, run one of the four drivers
    with `QT_QPA_PLATFORM=xcb QT_SCALE_FACTOR=2 pp/ppxvtest1_qt` as a
    SHELL-06 regression guard.
