    **Step 4 — Smoke-test each _qt executable (D-15):**
    For each of `ppmail_qt ppelas_qt ppflui_qt ppther_qt ppnlse_qt`, run it with stdin closed and a short timeout.     Because MEFISTO executables read from stdin interactively, we pipe `/dev/null` and apply a 5-second timeout:
    ```
    for e in ppmail_qt ppelas_qt ppflui_qt ppther_qt ppnlse_qt; do
      echo "=== Smoke-testing pp/$e ==="
      timeout 5s pp/$e < /dev/null > /tmp/$e.stdout 2> /tmp/$e.stderr
      EXIT=$?
      echo "exit=$EXIT  stderr-lines=$(wc -l < /tmp/$e.stderr)"
      # Acceptable outcomes:
      #   - exit 0 (clean no-op path)
      #   - exit 124 (timeout — binary ran but blocked waiting for stdin; that's fine)
      #   - exit 1 / non-crash (binary ran and exited; that's fine)
      # UNACCEPTABLE:
      #   - exit >= 128 and the specific signals 139 (SIGSEGV), 134 (SIGABRT), 135 (SIGBUS)
      if [ "$EXIT" = "139" ] || [ "$EXIT" = "134" ] || [ "$EXIT" = "135" ]; then
        echo "FAIL: pp/$e crashed with signal exit=$EXIT"
        cat /tmp/$e.stderr
        exit 1
      fi
    done
    echo SMOKE_TEST_OK
    ```
