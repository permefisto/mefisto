### Task 2 — Manual A/B sweep + hot-fix (commit 792394c)

Launched `pp/ppmail_qt` inside an isolated KWin session against a
fresh `$MEFISTOX/abtest` project (created via `bin/INITIER`) and drove
the UI via accessibility APIs + mouse/keyboard simulation:

**Verified working on first sweep:**

1. Window chrome — 1024×768 MEFISTO frame, File/View/Help menu bar, toolbar
   with icons + "Console (F9)" button, console dock visible by default at
   the bottom, status bar with live X/Y coord readout.
2. **D-08 modal re-entrancy guard** — After launching the mesher (which
   enters `xvsouris_` immediately), clicking Help → About correctly showed
   the exact D-08 status-bar message `"Finish current operation first
   (type 99;)"` and suppressed the dialog. Right-click context menu was
   also correctly silently suppressed during the blocking read (Plan 05
   `if (blockingDepth() > 0) return;`).
3. **mouseCoords readout** — Clicking at screen (640, 500) updated the
   status bar to `X: 512  Y: 360` — screen→canvas mapping correct, signal
   wiring live.
4. Help menu opens via Alt+H mnemonic (D-04 modifier rule).
5. Documentation (F1) correctly invoked `xdg-open` on `$MEFISTO/doc/`
   (failed gracefully in the isolated session — expected, no file manager
   in the isolated KWin environment).

**Defect surfaced and fixed inline:**

The Plan 05 empty-state hint ("No project open / Choose File → Open
Project (Ctrl+O) to get started.") was **visibly overlapping the live
POINTS & LINES mesher menu, project header, and right-side mouse-button
raster**. Root-caused to the Plan 06 comment at
`xvue_qt_api.cpp:1397`: "Pure 6.0 builds do [not call xvue_module_init_].
(6.1..6.5 add the CALL XVUE_MODULE_INIT lines)." — without the call,
`state->has_user_content_` stays `false` forever, so the empty-state
hint kept drawing on top of the mesher's active canvas chrome.

Fix applied as commit 792394c: added a tiny inline helper
`xvue_qt_mark_user_content()` in the anonymous namespace of
`xvue_qt_api.cpp` (flips the flag + triggers a single repaint; idempotent
on subsequent calls). Wired into every Fortran-callable drawing primitive
that mutates the backing pixmap: `xvue_qt_draw_rect_common`,
`xvue_qt_draw_text_common`, `xvue_qt_restore_from_slot`, `effacer`,
`effacemempx`, `xvfond`, `xvface`, `xvtrait`, `xvtraits`, `xvfacetraits`,
`xvbordarcellipse`, `xvarcellipse` (12 call sites total).

Re-ran the manual sweep post-fix: hint correctly disappears as soon as
the mesher paints its first frame. Regression suite re-run:
106 PASS / 1 FAIL (the same pre-existing timing flake) / 2 SKIP — no
new regressions. ABI stays at 58.
