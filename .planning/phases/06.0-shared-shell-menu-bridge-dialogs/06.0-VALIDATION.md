```bash
export MEFISTO=$(pwd)
export PATH=/tmp/gfortran-14-shim:$PATH
# libgfortran5 pinned to 15.2.0-9 per project memory
```

## Sampling Rate

- **After every task commit:** Run the task's `<automated>` verify command (per-plan subset — ~5-15 seconds)
- **After every plan wave:** Run full suite for that wave's binaries (~30-60 seconds)
- **Before `/gsd-verify-work`:** Full suite must be green, ABI=58, SHELL-03 grep=0
- **Max feedback latency:** ~60 seconds (per-wave full-suite run)
