### Frequency evidence source

`testa/gourd/gourd.ther` is the only canonical thermal batch script on this
worktree (4.3K). Its lexicon-block format wraps the codes in `;{ comment }`
multi-line blocks separated by blank lines, NOT the simple `[0-9]+; *\{`
single-line format used by .flui/.elas. The grep regex must accommodate:

```bash
# Adapted regex for ther multi-line block format
grep -hE "^ *[0-9]+;\\{| *[0-9]+; *\\{" testa/*/*.ther 2>/dev/null \
  | grep -oE "^ *[0-9]+;" | sort | uniq -c | sort -rn > /tmp/ther_freq.txt
```

If the regex returns 0 hits, fall back to a simpler scan that strips brace
content first:

```bash
sed 's/{[^}]*}//g' testa/*/*.ther 2>/dev/null \
  | grep -oE "^[[:space:]]*[0-9]+[[:space:]]*;" \
  | tr -d ' ' | sort | uniq -c | sort -rn > /tmp/ther_freq.txt
cat /tmp/ther_freq.txt
```

gourd is the ONLY .ther fixture):
