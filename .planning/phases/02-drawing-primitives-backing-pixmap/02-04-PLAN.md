    ellipse arc, holds the window for ~1 second (SLEEP(1)), then closes
    and reopens it.
  </what-built>
  <how-to-verify>
    Run:

    ```bash
    cd $MEFISTO
    pp/ppxvtest0_qt
    ```

    During the FIRST SLEEP(1) hold (before the first "[xvtest0] premier
    appel XVFERMER" line scrolls past), visually verify:

    1. **Geometry present (DRAW-02..05):** the canvas shows (on a black
       background) a horizontal white line, a connected polyline of 3
       points, a filled 4-point polygon, four rectangles side-by-side,
       a filled ellipse pie slice, and an outlined ellipse arc. If the
       canvas is pure black, DRAW-0{2,3,4,5} is broken.

    2. **Pen style variety (DRAW-06):** at least one line drawn with a
       dashed pattern (pen style 1 or 2) AND at least one line drawn with
       a thicker stroke after XVEPAISSEUR(2). If every line looks the
       same, DRAW-06 is broken.

    3. **Antialiasing (DRAW-08):** diagonal polyline segments and the
       ellipse arc show smooth edges, not stair-step aliased jaggies. If
       jagged, Pitfall 5 (hints not reapplied after begin) is triggered.

    4. **Clear mid-sequence (DRAW-07 effacer):** the final displayed
       content shows the POST-effacer draws only (one dashed horizontal
       line + one thicker dashed horizontal line near the bottom), NOT
       the rectangles/polygons from before the effacer call. If the
       pre-effacer geometry is still visible, effacer_ did not fill.

    5. **Resize preserve (DRAW-09):** while the window is held by SLEEP,
       grab the window edge and drag to RESIZE it LARGER. The previously
       drawn geometry MUST remain anchored at the top-left, with the new
       area filled black. If the content stretches, recenters, or
       disappears, DRAW-09 is broken and README_RESIZE.md invariants
       were not followed. If the content survives but the new area
       shows garbage, the background fill step in resizeEvent is missing.

    6. **Reopen cycle (SHELL-02 regression guard):** after the first
       XVFERMER, the second XVINITGRAPHIQUE must open a new window
       without any `QApplication: there can only be one` assertion on
       stderr. The second SLEEP(1) hold shows a blank (no drawn
       geometry) canvas, then the second XVFERMER closes cleanly.

    7. **Process exit clean:** after both cycles, `echo $?` should print
       `0`. No SIGSEGV, no Qt warnings about "Painter not active" or
       "QPixmap: Must construct a QGuiApplication before …".

    Optional additional coverage if a HiDPI display is available: run
    `QT_SCALE_FACTOR=2 pp/ppxvtest0_qt` and confirm the geometry
    renders at the expected scale (SHELL-06 + Pitfall 8).
