entry exists, capture on both backends and run font analysis as planned;
if not, document the gap and file an escalation request rather than
fabricating a capture by guessing.

- VALID-05: "Color-bar spot checks on testa/nafems_le1, heat1d, and cavity2d
  show no user-visible drift between backends." Pitfall 6 documents that
  gradient color bars routinely trip 5% fuzz; this plan computes AE inside
  the colorbar region only and proposes a per-case fuzz_override_pct for
  Plan 7 CHECKLIST.md cells.
- VALID-06: "Font-metric spot checks on testa/pan2d, hexahedron — no
  clipping or overlap." Pitfall 7 documents that AA + font hinting differ
  across backends; this plan sets a per-case AE budget (Pitfall 7 formula:
  ~200 px per glyph × ~15 labels ≈ 3000 px for pan2d) and verifies the
  diff PNG shows ONLY glyph-edge fringing, not missing/clipped/overlapping
  labels. **For hexahedron specifically**: probe-first → capture-or-document.

Output: 5 spot-check markdown reports + 1 hexahedron probe report + (if probe
succeeds) 2 hexahedron PNGs + 1 diff PNG + 1 aggregated summary. If probe
fails: 1 escalation entry in 08-VALIDATION.md asking maintainer to either
(a) provide a CONTEXT.md amendment naming the canonical hexahedron batch
file, or (b) waive VALID-06 hexahedron coverage with documented rationale.
