<objective>
Capture the Qt HiDPI 2x column for the 5 canonical testa cases under
QT_SCALE_FACTOR=2 + QT_QPA_PLATFORM=offscreen, then DOWNSAMPLE each capture to
the X11 baseline dimensions before invoking ab_compare_pair.sh -fuzz 5%
against the matching X11 baseline. This plan PRODUCES column 3 of the
CHECKLIST.md verdict matrix (Qt HiDPI 2x).

Purpose: VALID-04 demands "all 5 cases render correctly on a HiDPI display."
D-04 specifies QT_SCALE_FACTOR=2 under Xvfb (cheap, reproducible, headless)
as the ship-gate methodology. Pitfall 4 (Open Question 4) flags that the
backing pixmap is dpr-scaled, so a naive AE compare against the 1x X11
baseline would mismatch on dimensions. The fix is to resample the 2x capture
DOWN to baseline dims before compare. This plan operationalizes the fix.

Output: 5 capture PNGs (at 2x dims) + 5 diff PNGs (at 1x dims after resample) + 1 sweep log.
</objective>

<!-- HiDPI capture contract — Qt-side honors QT_SCALE_FACTOR; backing pixmap is physical (dpr-scaled). -->

QT_SCALE_FACTOR=2 contract (Qt 6 native):
  - QGuiApplication::primaryScreen() reports devicePixelRatio() == 2.
  - QPixmap created via XvueState::ensureBacking_(...) is sized to physical pixels (logical * dpr).
  - At Xvfb 1280x800 + QT_SCALE_FACTOR=2: logical canvas is 640x400, backing is 1280x800.
  - HOWEVER, if the test case calls xvinitgraphique_ with explicit dimensions matching the X11 baseline,
    the backing may be canvas-explicit-dims * dpr — verify per-case empirically.

xvue/qt/src/xvue_qt_api.cpp xvfermer_ saves st->backing_ — physical pixels regardless of dpr (verified by 08-RESEARCH.md A5).

Resampling contract (mitigates Pitfall 4):
  - convert "$qt2x_png" -filter point -resize "${X11_DIMS}!" "$qt2x_png_resampled"
  - point sampling avoids introducing AA pixels not in either source — keeps the AE compare honest.
  - ab_compare_pair.sh's built-in dimension guard performs this automatically when DA != DB.

bin/ab_sweep_phase8.sh --mode qt-2x dispatch (per Plan 1 Task 3 spec):
  env QT_SCALE_FACTOR=2 \
      QT_QPA_PLATFORM=offscreen \
      MEFISTO_QT_CAPTURE_PATH=$OUT_DIR/${CASE}-qt-2x.png \
      MEFISTO_XVSOURIS_AUTOEXIT=1 \
      MEFISTO_XVSOURIS_AUTOEXIT_DELAY_MS=500 \
      timeout 60 pp/pp${MODULE}_qt $BATCH

  Then: bin/ab_compare_pair.sh evidence/${CASE}-x11.png evidence/${CASE}-qt-2x.png evidence/${CASE}-qt-2x-diff.png 5
        (the dimension guard inside ab_compare_pair.sh detects size mismatch and resamples qt-2x DOWN to x11 dims using filter point.)
