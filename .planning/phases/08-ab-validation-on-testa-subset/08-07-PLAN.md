CELL CONTENT PIPE-CHARACTER ESCAPING (MINOR-11 from iter1 review):
  Plan 7 emits markdown tables. Cell content sourced from sweep logs may contain `|` characters
  (e.g., AE info strings, file paths with shell pipes, hypotheses, override notes). The Plan 7
  task's awk-based row-count verify gate counts column boundaries by `|` — un-escaped `|` inside
  cell content produces ghost columns and breaks the count.

  Rule: BEFORE writing any cell content into a CHECKLIST.md table, transform `|` characters as:
    - Replace `|` with HTML entity `&#124;` (preferred — markdown renders correctly), OR
    - Replace `|` with `;` (alternate — pure ASCII; less faithful but simpler)
  Apply this transform inside the Plan 7 ingest step that pulls cell content from sweep logs.
  Document the choice (entity vs semicolon) in the file header so future readers understand the
  encoding. Plan 7 verify gate exercises a known-good fixture row whose AE info contains `|`
  to confirm the transform fired.
