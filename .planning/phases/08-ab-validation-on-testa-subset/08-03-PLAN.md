xvue/qt/src/xvue_qt_api.cpp xvfermer_ contract (verified):
  - Reads getenv("MEFISTO_QT_CAPTURE_PATH") → if non-empty, st->backing_->save(QString::fromLatin1(path), "PNG").
  - Saves the BACKING pixmap (not the widget) — physical pixels.
  - At QT_SCALE_FACTOR=1 (default), backing dims = canvas dims = X11 baseline dims.
  - Honors MEFISTO_XVFERMER_READY_FILE + MEFISTO_XVFERMER_HOLD_MS for symmetry with X11 backend.

QT_QPA_PLATFORM=offscreen (Qt 6 native):
  - Renders to backing pixmap with NO X server. Confirmed by Phase 7 UAT.
  - No Xvfb required; xvfb-run is unnecessary in this plan.

bin/ab_sweep_phase8.sh --mode qt-1x dispatch (per Plan 1 Task 3 spec):
  env QT_QPA_PLATFORM=offscreen \
      MEFISTO_QT_CAPTURE_PATH=$OUT_DIR/${CASE}-qt-1x.png \
      MEFISTO_XVSOURIS_AUTOEXIT=1 \
      MEFISTO_XVSOURIS_AUTOEXIT_DELAY_MS=500 \
      timeout 60 pp/pp${MODULE}_qt $BATCH

  Then: bin/ab_compare_pair.sh evidence/${CASE}-x11.png evidence/${CASE}-qt-1x.png evidence/${CASE}-qt-1x-diff.png 5
